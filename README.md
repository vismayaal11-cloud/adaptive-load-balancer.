# Adaptive Load Balancer

A Computer Networks mini-project implementing an adaptive TCP load balancer
integrated with an SDN-based network.

## Project Overview

The system distributes client requests across two backend servers,
adapts to server load and health, and uses an SDN controller
to update network forwarding rules.
